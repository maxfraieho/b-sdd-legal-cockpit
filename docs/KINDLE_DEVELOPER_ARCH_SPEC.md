# ЧАСТИНА 1: Філософія B-SDD та Інваріанти

B-SDD (Bitemporal Spec-Driven Development) розглядає будь-який юридичний факт у двох незалежних часових вимірах:
- **Valid Time ($T_v$)**: часовий інтервал у фізичному світі, коли подія фактично мала місце.
- **Transaction Time ($T_t$)**: момент реєстрації інформації про подію в комп'ютерній системі чи протоколі слідчого.

### 5 Базових Інваріантів:
- **L-01 (Bitemporal Immutability)**: Заборона модифікації на місці (no in-place updates). Будь-яка правка створює новий вузол у криптографічному дереві із деактивацією старого.
- **L-02 (Zero External Dependencies)**: Логічне ядро (`src/legal/`) функціонує виключно на стандартній бібліотеці Python 3.
- **L-03 (Bona Fide Shield)**: Безумовний судовий імунітет добросовісного набувача та волонтера за ст. 933 Цивільного кодексу Швейцарії (справа Адріано Міллі).
- **L-04 (Minor / Victim Standing)**: Непорушний процесуальний статус потерпілої сторони (partie plaignante / ст. 115, 118 КПК).
- **L-05 (Cryptographic Proof)**: Обов'язкова наявність контрольної суми SHA-256 у кожного доказу.

# ЧАСТИНА 2: Архітектура Авторизації (AuthGate v2.6)

Архітектура захисту реалізує двоетапний шлюз:
1. **Етап 1: Stealth Shield**:
   - Перевірка PIN-коду без доступу до бази даних досьє.
   - Повне маскування імен, адрес, номерів кримінальних справ та змісту клопотань.
   - Підтримка 5 мов інтерфейсу: UK, FR, DE, IT, EN.
2. **Етап 2: Google Whitelist & RBAC**:
   - Валідація облікового запису Google проти списку дозволених адрес.
   - Розмежування прав за ролями: `super_admin`, `admin`, `lawyer`, `user`.
   - Сесійний контроль у `sessionStorage` з автоблокуванням через 15 хвилин бездіяльності.

# ЧАСТИНА 3: Захист Таємниці Слідства та WORM Ledger

- **Відповідність ст. 73 КПК Швейцарії (Secret de l'instruction)**:
  - Усі матеріали справи зберігаються локально в браузері клієнта (IndexedDB / LocalStorage) або на суверенному WORM-сервері Utopia DB.
  - Локальний штучний інтелект (Private RAG) працює без витоку даних на зовнішні комерційні сервери.
- **Криптографічний реєстр WORM (Write Once, Read Many)**:
  - Кожна фіксація доказу створює незмінний блок із гешем попереднього блоку та електронною печаткою за стандартом ISO/IEC 27037.

# ЧАСТИНА 4: Пайплайн Збірки та Cloudflare Pages

Проєкт автоматизовано розгортається на платформі Cloudflare Pages через CLI `wrangler`:
1. Виконання pre-flight перевірок: `python3 -m unittest discover tests`.
2. Компіляція клієнтського бандлу: `npm run build` у `b-sdd-legal-ui/`.
3. Публікація артефактів:
   `CLOUDFLARE_ACCOUNT_ID='...' CLOUDFLARE_API_TOKEN='...' npx wrangler pages deploy dist/ --project-name='b-sdd-legal-ui' --branch=main`.

# ЧАСТИНА 5: Автономний Компілятор EPUB 3.0

Скрипт `scripts/generate_legal_book.py` реалізує пряму генерацію книг стандарту EPUB 3.0 без застосування Calibre чи Pandoc:
- Генерує структуру `mimetype`, `META-INF/container.xml`, `OEBPS/content.opf`, `OEBPS/nav.xhtml`.
- Конвертує Markdown-файли у семантичний валідний XHTML.
- Забезпечує коректне відображення на читалках Kindle Paperwhite та сумісність із сервісом Amazon Whispersync.
