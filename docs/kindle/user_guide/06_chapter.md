# РОЗДІЛ 6: Інструкція з Експлуатації Модулів

- **Експорт на Kindle**: Натискання кнопки «Надіслати на Kindle» компілює всі розділи в EPUB 3.0 та передає на зареєстровану адресу Kindle (`tu***@kindle.com`).
- **Електронний папір**: Режим E-Ink Paperwhite вмикається в один клік для читання в умовах яскравого освітлення зали судових засідань.
- **Блокування сесії**: Іконка замка миттєво приховує екран та повертає систему на PIN-бар'єр.
