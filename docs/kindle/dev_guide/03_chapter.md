# ЧАСТИНА 3: Захист Таємниці Слідства та WORM Ledger

- **Відповідність ст. 73 КПК Швейцарії (Secret de l'instruction)**:
  - Усі матеріали справи зберігаються локально в браузері клієнта (IndexedDB / LocalStorage) або на суверенному WORM-сервері Utopia DB.
  - Локальний штучний інтелект (Private RAG) працює без витоку даних на зовнішні комерційні сервери.
- **Криптографічний реєстр WORM (Write Once, Read Many)**:
  - Кожна фіксація доказу створює незмінний блок із гешем попереднього блоку та електронною печаткою за стандартом ISO/IEC 27037.
